Forking Paths Lab

Every analysis passes through many small decisions. Here a coding agent surfaces each one as it comes up, explains the options and recommends one. You choose the main path and mark the alternatives you find plausible, and the multiverse on the right recomputes live. Nothing stays implicit: the choices become a decision log, and the code that implements them is open for review.

Agent proposes→Researcher decides→Agent implements→Multiverse tests sensitivity→Researcher reviews the code
Runs on 150 synthetic interviews from the democracy-interviewer repo. Not real findings.

Guarding against the agent's own framing. An agent shapes which options a researcher sees and which choices look too obvious to question. Two features push back: each decision lists the options the agent considered but did not offer, and a skeptical reviewer question that argues against the recommended path. Both are part of the log.

    
What is computed. Outcomes are the share of respondents with an action paradox (a principle named in module A, acted against in module C) and with an expectation gap (an expectation from module B seen as badly delivered). The LLM-annotator branch is logged but runs only with a configured model, so it is excluded here. Built by Tansif Anzar; the same logic runs in python -m analysis.multiverse.
